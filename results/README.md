# Results

This directory contains the numerical outputs used to build the final comparisons in the research paper and project README.

Important files:

- `FINAL_master_results.csv` — consolidated Phase I and Phase II metrics.
- `FINAL_key_findings.csv` — compact summary of the main quantitative findings.
- `phase2_analysis_protocol.csv` — reported Phase II analysis settings.
- `binary_final_comparison.csv` — binary CWRU model comparison.
- `multiclass_final_comparison.csv` — multiclass CWRU model comparison.
- `phase2_test2_sensitivity_summary.csv` — calibration-sensitivity summary.
- `phase2_test1_validation.csv` — Test 1 sensor-trajectory alarm comparison.

Phase II lead values should be interpreted as **anomaly lead relative to the conventional RMS alarm**, not as direct remaining-useful-life estimates.
